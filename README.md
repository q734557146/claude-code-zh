# Claude Code 中文补丁

Claude Code / Claude Desktop 中文汉化补丁，主要用于将官方直连 1P 模式下的 Claude Code 界面汉化为简体中文。

本补丁通过本地资源补丁和 renderer / DOM 层文本替换实现汉化，不修改账号、不代理网络、不破解功能，仅用于改善中文用户的界面阅读体验。

## 适用范围

- 支持：Windows 版 Claude Desktop / Claude Code
- 支持：官方直连 1P 模式
- 暂不支持：3P 模式
- 暂不支持：非官方客户端、第三方魔改客户端

如果你使用的是官方 Claude Desktop，并且 Claude Code 可以正常打开，一般可以使用本补丁。

## 功能特点

- 汉化 Claude Code 主界面
- 汉化菜单、设置、提示、弹窗、Toast 通知
- 汉化 Claude Code 设置页
- 汉化部分插件、技能、更新日志等页面
- 支持安装前自动备份
- 支持卸载并还原
- 安装完成后自动重启 Claude Desktop

## 使用方法

1. 下载 Release 中的 Windows 汉化补丁安装包。
2. 双击运行安装器。
3. 根据提示确认安装。
4. 安装器会自动关闭 Claude Desktop，写入补丁后重新打开。
5. 重新进入 Claude Code 查看汉化效果。

安装过程中如有安全软件提示，请根据实际情况自行判断是否允许。
